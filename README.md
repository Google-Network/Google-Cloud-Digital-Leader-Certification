A dedicated, comprehensive study guide and cloud knowledge reference repository for candidates preparing for the **Google Cloud Digital Leader Certification Exam**.

---

## Exam Overview

The Google Cloud Digital Leader certification validates foundational knowledge of cloud computing, Google Cloud products, and how cloud technologies support business goals and digital transformation.

- **Exam Format**: Multiple-choice and multiple-select questions; online-proctored or onsite-proctored.
- **Target Audience**: Business professionals, project managers, decision-makers, and individuals working with technical teams.
- **Prerequisites**: None; experience collaborating with technical professionals is recommended.

---

## Core Exam Domains & Knowledge Areas

### 1. Digital Transformation with Google Cloud

- Cloud computing concepts, business value, and digital transformation.
- Public, private, hybrid, and multicloud models; IaaS, PaaS, and SaaS.
- Google Cloud infrastructure, scalability, flexibility, and shared responsibility.

### 2. Exploring Data Transformation with Google Cloud

- The value of data, data governance, databases, data warehouses, and data lakes.
- Google Cloud data services, including BigQuery, Cloud Storage, Cloud SQL, and Spanner.
- Data analytics, business intelligence, streaming analytics, and data pipelines.

### 3. Innovating with Google Cloud Artificial Intelligence

- AI and machine learning fundamentals, business value, and responsible AI.
- Google Cloud AI/ML solutions and selecting services for business use cases.
- Generative and predictive AI concepts, model development, and Google Cloud AI products.

### 4. Modernize Infrastructure and Applications with Google Cloud

- Cloud migration strategies and infrastructure or application modernization.
- Compute options, virtual machines, containers, Kubernetes, and serverless computing.
- APIs, hybrid cloud, multicloud, and modern application architectures.

### 5. Trust and Security with Google Cloud

- Cloud security fundamentals, cybersecurity risks, and shared responsibility.
- Identity and access management, encryption, authentication, and network protection.
- Google Cloud trust principles, compliance, data sovereignty, and data residency.

### 6. Scaling with Google Cloud Operations

- Financial governance, cloud cost management, budgets, and resource controls.
- Operational excellence, reliability, resilience, monitoring, and disaster recovery.
- Google Cloud support, sustainability, and efficient cloud operations.
